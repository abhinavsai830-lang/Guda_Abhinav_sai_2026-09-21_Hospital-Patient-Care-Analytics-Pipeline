# Hospital Patient Care Analytics Pipeline

## Project Overview

An end-to-end data engineering pipeline for integrating
hospital patient data from multiple systems.

## Case Study Goals

1. Reduce patient waiting times
2. Improve patient care
3. Identify high-risk patients

## Data Sources

- Patient Registration System
- Appointment Scheduling System
- Laboratory System
- Wearable Health Devices
- Doctor Consultation Notes

## Architecture

Sources
    ↓
Extract
    ↓
Transform
    ↓
Validate
    ↓
Load into MySQL
    ↓
SQL Analytics
    ↓
Dashboard

## Technology Stack

- Python
- Pandas
- NumPy
- MySQL
- SQLAlchemy
- Matplotlib
- Streamlit
- Pytest
